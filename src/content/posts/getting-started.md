这是「学而记」的第一篇文章，也是一份随时可以回来看的写作说明。等真正的学习笔记多起来后，可以修改或删除它。

## 一篇笔记，从几个问题开始

不必把每一篇都写成完整教程。刚学完时，先留下最容易忘掉的部分：

- **学了什么？** 用自己的话概括这次学习的内容。
- **哪里卡住了？** 记录当时的问题，以及怎样找到答案。
- **能用在哪里？** 留一个例子、一段代码，或一次实际尝试。
- **还有什么没懂？** 给下次回来看留一条线索。

## 添加一篇文章

在博客项目的 `src/content/posts/` 目录下，新建一个 Markdown 文件，例如 `my-first-note.md`。文件名会成为文章网址的一部分，建议使用小写英文和短横线，发布后尽量保持不变。

把下面的内容复制进去，再改成自己的标题、日期、摘要和正文：

```yaml
---
title: "我的第一篇学习笔记"
pubDatetime: 2026-11-07T10:00:00+08:00
description: "用一两句话说明这篇笔记记录了什么。"
tags: ["学习笔记"]
draft: false
---
```

元信息下方就是正文。`pubDatetime` 填实际发布日期，时区使用 `+08:00`（北京时间）。修改旧文章时，可以另外添加 `modDatetime` 记录更新时间。

## 常用 Markdown 写法

### 标题与列表

用 `##` 表示正文中的一级小标题，用 `###` 表示下一层。页面已经有文章标题，正文不必再写一遍 `# 标题`。标题较多时会自动生成文章目录。

```markdown
## 今天学到什么

这里写正文，可以使用 **加粗** 标出重点。

- 第一个要点
- 第二个要点

> 留下一句值得回看的提醒。
```

### 代码与链接

代码块开头可以注明语言，博客会自动高亮。例如：

```python
notes = ["先理解", "再实践", "用自己的话记下来"]
for note in notes:
    print(note)
```

普通链接写成 `[链接文字](https://example.com)`。

### 插入图片

可以把图片放在文章旁边，再用相对路径引用。比如文章和 `diagram.png` 放在同一个文件夹中：

```markdown
![图片说明](./diagram.png)
```

使用相对路径，发布到博客子目录时也不需要手动修改图片网址。

## 预览与发布

第一次在电脑上使用项目，需要安装 Node.js 和 pnpm，并在博客项目目录执行 `pnpm install`。

日常写作时运行：

```bash
pnpm dev
```

打开终端提示的本地网址，就能边写边预览。准备好后运行 `pnpm build` 检查文章格式并生成搜索索引。

把改动提交并推送到 GitHub 的 `main` 分支，网站就会自动构建和更新。也可以直接在 GitHub 网页中添加或修改 Markdown 文件。

## 关于草稿

`draft: true` 的文章不会出现在博客页面、搜索结果和订阅中。准备发布时，把它改成 `draft: false` 再提交即可。

这个博客的 GitHub 仓库是公开的，草稿文件提交后仍然可以在仓库里被看到。私人内容请留在电脑上，不要提交到仓库。
